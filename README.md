# 아발론 온라인 V2
친구들과 비공개로 플레이하기 위한 Node.js + Socket.IO 웹게임 프로토타입.

## V2 주요 기능
- 5~10명 방
- 방 코드 참가
- 게임 시작 전 역할 조합 설정
- 제공받은 역할 카드 이미지 사용
- 역할 비공개 배정 및 정보 공개
- 첫 왕 선택
- 왕만 원정대 선택
- 시간 제한 없음
- 투표
- 원정 성공/실패
- 라운드 종료 후 방장 버튼으로 다음 라운드
- 다음 왕 자동 변경
- 3승/3패
- 7명 이상 4번째 원정 2실패
- 5회 연속 원정대 거부
- 선의 3승 후 암살자의 멀린 지목
- 모바일 반응형 UI

## 실행
Node.js 18+ 권장:
npm install
npm start
그리고 http://localhost:3000

## 공개 배포
Render/Railway/Fly.io/VPS 등 Node.js 서버에서 실행하면 친구들이 URL로 접속할 수 있습니다.
카드 이미지의 공개 배포 권리는 별도로 확인하세요.
